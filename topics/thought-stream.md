# Thought Stream

Moment-in-time capture of raw topic seeds, written down fast so they are not lost
and can be revisited later. These are **not** structured topics, and there is no lifecycle
here. When an entry earns deeper consideration, promote it into a real
[`TOPIC-###`](README.md) file and (optionally) strike it through or remove it below.

Entries are a flat list, newest at the bottom. Added via the `capture-topic` skill.
Plain ideas go in [`idea-stream.md`](idea-stream.md) via the `capture-idea` skill.
